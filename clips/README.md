# Real video clips

Any video or photo you upload to this `clips` folder automatically plays in the Naymo feed, as other creators' posts and as LIVE backgrounds.

How to add clips (works on a phone):
1. Download free vertical (portrait) videos, for example from pexels.com, mixkit.co or pixabay.com (no account needed).
2. On github.com, open this `clips` folder, tap **Add file → Upload files**, pick the videos and tap **Commit changes**.
3. Reopen the app after a minute.

Tips:
- Use `.mp4` files under about 20 MB each so they load fast.
- Words in the file name pick which videos they show up on: `cat`, `dog`, `cooking`, `ramen`, `coffee`, `gym`, `dance`, `city`, `beach`, `sunset`, `music`, `rain`, `snow`, `makeup`, `gaming`, `space`.
  Example: `cat-sleeping.mp4` plays on pet videos.
