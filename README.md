# Naymo

A TikTok-style app in a single HTML page. Open `index.html`, or visit the GitHub Pages site.

- `index.html` is the built app. Don't edit it by hand.
- `src/` holds the source parts. Run `./build.sh` after changing them to rebuild `index.html`.
- All app data (posts, likes, comments, settings, uploaded clips) is stored in the visitor's own browser.
